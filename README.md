# 오늘의 공기

전국 17개 시·도의 미세먼지(PM10)·초미세먼지(PM2.5)를 한 화면에서 비교하는 웹 서비스.
시·도 칩·지도·순위 어느 쪽을 눌러도 같은 지역이 선택된다.

- **빌드 도구 없음** — 바닐라 ES 모듈 + CSS. `npm install` 이 필요 없고, 파일을 그대로 올리면 동작한다.
- **API 키가 브라우저로 나가지 않음** — GitHub Actions 가 서버 쪽에서 데이터를 받아 `data/air.json` 으로 커밋하고, 프론트는 그 정적 JSON 만 읽는다.
- **CORS 문제 없음** — 같은 오리진의 정적 파일이라 교차 출처 요청 자체가 없다.

---

## 1. 왜 이런 구조인가

GitHub Pages 는 정적 호스팅이라 서버리스 함수를 둘 수 없다. 브라우저에서 공공데이터포털 API 를 직접 부르면 두 가지가 동시에 터진다.

1. **인증키 노출** — `serviceKey` 가 네트워크 탭과 소스에 그대로 드러난다. 도용당하면 일일 호출 한도가 남에 의해 소진된다.
2. **CORS** — 공공데이터포털은 교차 출처 요청용 헤더를 보장하지 않는다. 로컬 개발에서는 프록시로 가려지다가 **배포 후에만 실패**하는 전형적인 함정이다.

그래서 데이터 수집을 빌드 타임(정확히는 스케줄된 CI)으로 옮겼다.

```
GitHub Actions (매시 25분)
   │  SERVICE_KEY 는 Secrets 에만 존재
   ▼
apis.data.go.kr  ──►  scripts/fetch-air.mjs  ──►  data/air.json 커밋
                                                       │
                                                       ▼
                                        브라우저가 정적 JSON 만 fetch
```

원본 데이터가 1시간 주기로 갱신되므로 신선도 손해는 없다.

### 호출 1회로 17개 시·도를 모두 얻는 방법

`getCtprvnRltmMesureDnsty` 는 **시·도 평균이 아니라 측정소 단위 원시 데이터**를 반환한다.
시·도별 값이 필요하다고 17번 호출하면 화면 한 번 갱신에 17회를 쓰게 되고, 개발계정 한도(일 500회)를 30회 갱신 만에 소진한다.

`sidoName=전국` 으로 **1회 호출**해 전국 측정소(약 600개)를 받은 뒤 시·도별로 평균을 낸다.
지도·순위·상세에 필요한 값이 호출 1회로 전부 확보되고, 하루 24회만 쓴다.

## 2. 설치

### 2-1. 공공데이터 인증키 발급

1. [공공데이터포털](https://www.data.go.kr) 회원가입
2. **한국환경공단_에어코리아_대기오염정보** 검색 → 활용신청 (자동 승인)
3. 마이페이지 → 오픈API → 인증키에서 **일반 인증키(Decoding)** 값을 복사

> ⚠️ Encoding 키가 아니라 **Decoding 키**를 쓴다. `scripts/fetch-air.mjs` 는 `URLSearchParams` 로 직접 인코딩하므로, 이미 인코딩된 키를 넣으면 `%` 가 이중 인코딩되어 인증에 실패한다.

### 2-2. 리포지토리 설정

```bash
git clone <your-repo> today-air
cd today-air
```

**Settings → Secrets and variables → Actions → New repository secret**

| Name | Value |
| --- | --- |
| `AIRKOREA_SERVICE_KEY` | 위에서 복사한 Decoding 인증키 |

**Settings → Actions → General → Workflow permissions** 에서 `Read and write permissions` 를 켠다.
(워크플로가 `data/air.json` 을 커밋해야 한다.)

**Settings → Pages** 에서 Source 를 `Deploy from a branch` → `main` / `/ (root)` 로 설정한다.

### 2-3. 첫 데이터 수집

**Actions → 미세먼지 데이터 갱신 → Run workflow** 로 수동 실행한다.
성공하면 `data/air.json` 이 실제 값으로 갱신되고, 이후 매시 25분에 자동으로 돈다.

## 3. 로컬에서 보기

빌드가 없으므로 정적 서버만 있으면 된다. (ES 모듈은 `file://` 에서 동작하지 않으니 반드시 서버로 연다.)

```bash
python3 -m http.server 8000
# 또는
npx serve .
```

http://localhost:8000 접속. 저장소에 들어 있는 `data/air.json` 은 샘플 데이터이며,
실제 값을 보려면 인증키로 직접 받아 온다.

```bash
SERVICE_KEY=발급받은키 node scripts/fetch-air.mjs
```

## 4. 구조

```
index.html                     마크업 (뼈대만, 내용은 JS 가 채운다)
assets/
  config.js                    시·도 목록, 등급 기준·색상·행동 요령  ← 도메인 규칙은 전부 여기
  map-data.js                  시·도 SVG path (자동 생성)
  app.js                       상태·렌더링·이벤트
  style.css                    색 토큰과 레이아웃
data/air.json                  Actions 가 갱신하는 유일한 데이터 소스
scripts/fetch-air.mjs          API 호출 + 시·도별 집계
.github/workflows/update-air.yml
```

### 데이터 형식 (`data/air.json`)

```json
{
  "dataTime": "2026-08-19 14:00",
  "fetchedAt": "2026-08-19T05:25:11.000Z",
  "stationCount": 612,
  "source": "한국환경공단 에어코리아 대기오염정보 (공공데이터포털)",
  "regions": {
    "서울": { "pm10": 42, "pm25": 21, "stations": 40, "pm10Stations": 40, "pm25Stations": 39 }
  }
}
```

값이 `null` 이면 **결측**이다. 0 이 아니다 — 이 구분이 무너지면 데이터가 없는 지역이 "좋음"으로 표시된다.

### 집계 규칙

- 시·도 값 = 해당 시·도 측정소들의 **유효 측정값 산술 평균** (소수 첫째 자리)
- 유효 조건: 숫자로 파싱되고 **flag 가 비어 있을 것** (`점검및교정`, `자료이상`, `통신장애` 는 제외)
- 유효 측정소가 0개면 `null` → 화면에서 "정보 없음"
- 등급은 측정소별 등급을 평균내지 않는다. **평균 농도를 구한 뒤 기준표에 대입해 재산정**한다 (등급의 평균은 의미가 없다)
- 17개 중 유효 시·도가 9개 미만이면 원본 장애로 보고 **기존 파일을 덮어쓰지 않는다**

### 등급 기준 (에어코리아)

| 등급 | PM10 (㎍/㎥) | PM2.5 (㎍/㎥) |
| --- | --- | --- |
| 좋음 | 0 ~ 30 | 0 ~ 15 |
| 보통 | 31 ~ 80 | 16 ~ 35 |
| 나쁨 | 81 ~ 150 | 36 ~ 75 |
| 매우나쁨 | 151 이상 | 76 이상 |

지역 대표 등급은 PM10·PM2.5 중 **나쁜 쪽**을 따른다.

---

## 5. 접근성 메모

- 등급은 **색 단독으로 표현하지 않는다.** 어디서든 색 + 텍스트 라벨(+ 아이콘)이 함께 간다.
- 지도에도 수치를 직접 찍는다. 색만 보고 판단해야 하는 상황을 만들지 않는다.
- 지도의 색상 구분이 어려운 경우를 위해 같은 정보를 **전국 순위 목록**에서 표 형태로 제공한다.
- 칩은 `←/→/Home/End` 로 이동, 지도 영역은 `Tab` + `Enter` 로 선택 가능하다.
- 작은 광역시(서울·인천·세종·대전 등)는 지도에서 면적이 작아, 반지름 15의 원형 히트 타깃을 따로 덧씌웠다.
- 다크 모드는 자동(`prefers-color-scheme`) + 헤더의 토글 수동 전환을 모두 지원한다.

## 6. 공유 링크

`?sido=충남` 처럼 쿼리 파라미터로 특정 지역을 바로 열 수 있다. 지역을 바꾸면 URL 도 같이 갱신된다.
